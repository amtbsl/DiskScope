# DiskScope Parity Implementation Plan

> **For agentic workers:** Use bounded parallel workers per the dispatching-parallel-agents skill, then integrate and review as one application. Steps use checkbox syntax for tracking.

**Goal:** Resolve the audited defects and missing local features and deliver a usable macOS 1.1.0 app.
**Architecture:** Preserve native AppKit/WebKit bridge. Separate search, app ownership and native quick-search services where helpful; the main agent integrates bridge actions and packaging.
**Tech Stack:** Swift 5 mode, AppKit, WebKit, IOKit, Carbon, local JS/CSS, Python/Node tests.
**Spec:** docs/superpowers/specs/2026-10-28-parity-design.md

## Global Constraints
- Independent app; macOS 12+; arm64 and x86_64 compile; no added runtime packages.
- No sudo, no privileged deletion, no automatic cleanup; uncertain/shared/system helper selections default off.
- Tests never delete personal files. No notarization/runtime Intel claims without evidence.

## Review Focus
- Symlink aliases to protected roots, self bundle descendants and changing running applications.
- More than 500 Spotlight candidates; filter-before-limit; large-file directory exclusion and ranking.
- Shared vendor data, helper plist ownership, missing permission/index information.
- Global hotkey conflicts, stale/out-of-order search results, focus and theme propagation.
- Offline/invalid update responses; strict fixed GitHub destination; two executable architectures.
